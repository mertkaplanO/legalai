# 🏛️ AI-Powered Legal Assistant

This project is a **Flask-based legal AI assistant** using **Ollama's ALIENTELLIGENCE/attorney2 model**. It answers legal questions in real time with a simple web interface.

## 🚀 Features  
✔ AI-powered legal Q&A  
✔ Scalable Flask backend  
✔ Easy-to-use HTML/CSS UI
